# Ricky 幻觉防治手册

> Ricky's AI Hallucination Prevention Manual — 一份给 AI（尤其 Hermes Agent）用的「防幻觉」操作手册。

## 这是什么

AI 是语言模型，不是知识库；而且它没有「不知道」这个选项——被问到就必须说点什么，于是就会硬编出「最像正确答案」的话。**这就是幻觉的根源。**

这份手册把防止 AI 幻觉的方法整理成一套可执行的操作纪律：用 **联网 + 引源 + 验证 + 明确说「不知道」** 四件套，大幅降低幻觉率。

## 内容概览

- **四大支柱**：检索优先 / 问法要求 / 温度参数 / 多轮验证
- **五类常见问题对策**：上下文遗忘、偏见立场、时效性、过度自信、短路回答
- **落地配方**：curl 直连一手来源（GitHub API/raw、HuggingFace 镜像、厂商文档、搜索引擎兜底）的现成命令
- **交付格式**：结论必须带来源 + 原文片段，没验证到的明确写「未核实」

## 目录结构


## 怎么用

- **Hermes Agent**：把本目录（skill 名 `ricky-hallucination-prevention-manual`）放进 `skills/` 目录，对话中涉及「下结论、报数据、引政策、给事实」时加载即可。
- **其他 AI / 人**：直接按 `SKILL.md` 里的清单自检——能不能降幻觉，取决于执行时是否真去查、真引源、真说不知道。

## 价值评估（作者诚实判断）

**有用之处：**

- 对**会联网检索、需要结论带来源**的 agent 场景，这是一套可落地的纪律清单。
- 明确点破了幻觉的根源（模型不会说「不知道」），并给出「主动留退路」的对策。
- curl 配方是实测踩坑整理，照着抄就能核实一手事实。

**局限：**

- 对纯离线、不联网的模型价值有限——第一条「检索优先」无处落地。
- 它不是魔法，是纪律：效果完全取决于执行时是否真的照做。
